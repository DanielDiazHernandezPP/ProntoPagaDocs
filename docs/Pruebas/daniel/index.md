Se le puede pasar un bgColor (valor hexadecimal con su '#' al principio), mode (light o dark), type (default o simple)

* Crear nuevo endopoint: Ecuador Wallet (with customized form)
* Subir a postman
* Crear ejemplo 200 y 400
