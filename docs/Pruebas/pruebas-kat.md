<Tabs>
  <Tab title="A">
    ### API
    Conjunto de reglas, protocolos y endpoints que permiten que tu sistema de software se comunique con otro...
  </Tab>

  <Tab title="B">
    ### Back-end
    La capa del servidor que procesa la lógica de negocio...

    ### Balance Disponible
    Es el monto que realmente está listo para ser retirado...
  </Tab>

  <Tab title="C">
    ### Certificación
    Proceso formal en donde se valida que una integración cumple todos los requisitos...
  </Tab>

  <Tab title="D">
    ### Desarrollador
    Persona encargada de crear, mantener y mejorar aplicaciones de software...

    ### Documentación
    Conjunto de materiales informativos que describen el funcionamiento, configuración y uso de un sistema...
  </Tab>

  <Tab title="E">
    ### Endpoint
    Punto de comunicación específico en una API donde se pueden realizar solicitudes...

    ### Entorno de Producción
    Ambiente operativo donde se ejecutan las aplicaciones en vivo para usuarios finales...
  </Tab>

  <Tab title="F">
    ### Front-end
    La interfaz de usuario visible que interactúa directamente con los usuarios...

    ### Flujo de Pago
    Secuencia de pasos que sigue una transacción desde su iniciación hasta su finalización...
  </Tab>

  <Tab title="I">
    ### Integración
    Proceso de conectar diferentes sistemas o aplicaciones para que trabajen juntos...

    ### iFrame
    Elemento HTML que permite incrustar contenido de una página web dentro de otra...
  </Tab>

  <Tab title="P">
    ### Pay-in
    Proceso de recibir pagos de clientes hacia tu cuenta comercial...

    ### Pay-out
    Proceso de enviar dinero desde tu cuenta comercial hacia cuentas de terceros...

    ### Parámetros
    Variables que se envían en las solicitudes API para especificar información necesaria...
  </Tab>

  <Tab title="Q">
    ### QR Code
    Código de barras bidimensional que almacena información y puede ser escaneado por dispositivos móviles...

    ### Query Parameters
    Parámetros adicionales que se agregan al final de una URL para enviar datos específicos...
  </Tab>

  <Tab title="S">
    ### Sandbox
    Entorno de pruebas aislado donde los desarrolladores pueden probar integraciones sin afectar datos reales...

    ### SDK
    Kit de desarrollo de software que proporciona herramientas, bibliotecas y documentación...

    ### Signature/Firma
    Mecanismo de seguridad que valida la autenticidad e integridad de los datos enviados...
  </Tab>

  <Tab title="T">
    ### Token
    Cadena de caracteres que actúa como credencial de autenticación para acceder a recursos protegidos...

    ### Transacción
    Operación completa de transferencia de dinero entre dos partes...

    ### Timeout
    Tiempo límite establecido para esperar una respuesta antes de considerar que ha fallado...
  </Tab>

  <Tab title="W">
    ### Webhook
    Mecanismo que permite a una aplicación enviar datos automáticamente a otra aplicación cuando ocurre un evento específico...

    ### Web Service
    Sistema de software diseñado para permitir la comunicación entre aplicaciones a través de internet...

    ### Wallet/Billetera Digital
    Aplicación que almacena información de pago y permite realizar transacciones electrónicas de forma segura...
  </Tab>
</Tabs>
