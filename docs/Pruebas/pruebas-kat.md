<Tab title="A">

### **API**
Conjunto de reglas, protocolos y endpoints que permiten que tu sistema de software se comunique con otro. En el sector de pagos, las APIs permiten operaciones como crear cobros, consultar transacciones, iniciar reembolsos o programar payouts.

---

</Tab>

<Tab title="B">

### **Back-end**
Capa del servidor donde se ejecuta la lógica de negocio y se gestionan webhooks, llaves secretas, órdenes y conciliaciones.

### **Balance Disponible**
Monto inmediatamente retirable. Se obtiene restando al saldo neto el saldo diferido y el bloqueado.

---

</Tab>

<Tab title="C">

### **Certificación**
Proceso donde se valida que una integración cumple requisitos técnicos y de seguridad antes de pasar a producción.

---

</Tab>

<Tab title="D">

### **Desarrollador**
Persona encargada de crear, mantener e integrar sistemas.

### **Documentación**
Material que describe el funcionamiento, configuración y uso de una API o plataforma.

---

</Tab>

<Tab title="E">

### **Endpoint**
Punto de acceso a una API donde se ejecuta una operación.

### **Entorno de Producción**
Ambiente real donde se procesan transacciones con dinero verdadero.

---

</Tab>

<Tab title="F">

### **Front-end**
Interfaz visible para el usuario donde se capturan datos y se muestran formularios.

### **Flujo de Pago**
Secuencia de pasos de una transacción desde su inicio hasta su resultado final.

---

</Tab>

<Tab title="I">

### **Integración**
Proceso de conectar sistemas o aplicaciones para que trabajen juntos.

### **iFrame**
Elemento que permite incrustar contenido de una página dentro de otra, usado para capturar datos sensibles de manera segura.

---

</Tab>

<Tab title="P">

### **Pay-in**
Entrada de dinero hacia tu cuenta comercial.

### **Pay-out**
Salida de dinero hacia cuentas de terceros o del comercio.

### **Parámetros**
Datos enviados en solicitudes API que definen comportamiento y contenido de una operación.

---

</Tab>

<Tab title="Q">

### **QR Code**
Código bidimensional que almacena información para pagos o enlaces a checkouts.

### **Query Parameters**
Valores enviados en la URL para filtrar o agregar datos a la solicitud.

---

</Tab>

<Tab title="S">

### **Sandbox**
Entorno de pruebas donde se pueden ejecutar transacciones ficticias.

### **SDK**
Conjunto de herramientas, librerías y documentación para integrar una API.

### **Signature / Firma**
Mecanismo de seguridad que valida integridad y autenticidad de los datos.

---

</Tab>

<Tab title="T">

### **Token**
Credencial de autenticación para acceder a recursos protegidos.

### **Transacción**
Operación financiera con estados y trazabilidad.

### **Timeout**
Tiempo máximo para esperar respuesta antes de marcar un fallo.

---

</Tab>

<Tab title="W">

### **Webhook**
Notificación automática enviada por la plataforma cuando ocurre un evento.

### **Web Service**
Sistema diseñado para permitir comunicación entre aplicaciones vía internet.

### **Wallet / Billetera Digital**
Aplicación que almacena métodos de pago y permite transacciones seguras.

---

</Tab>

</Tabs>
