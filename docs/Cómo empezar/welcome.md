Nuestra API te permitirá integrar nuestra amplia variedad de métodos de pago. La documentación de **ProntoPaga** está diseñada para guiarte paso a paso en el proceso, asegurando que tengas todo lo necesario para comenzar a usar nuestra API de forma exitosa.

En **ProntoPaga**, somos líderes en el procesamiento de pagos en Latinoamérica, distinguiéndonos por nuestra rapidez y eficiencia en las transacciones. Nuestra plataforma ofrece una amplia gama de métodos de pago, incluyendo tarjetas de crédito, débito, prepago, pagos en efectivo y transferencias bancarias, garantizando así accesibilidad para todos, desde individuos hasta negocios. **Todo con una sola integración.**

## 🚀 ¿Cómo empezar?

1. **Explora nuestras guías**: Ya sea que necesites saber cómo funciona un método de pago en particular o comprender el flujo completo de una transacción, nuestras guías detalladas te ayudarán a navegar por los diferentes escenarios. [Consulta las guías](https://docs.prontopaga.com/docs/payins-overview) para explorar todas las posibilidades.
2. **Primeros pasos**: Si es tu primera vez aquí, te recomendamos empezar con nuestra [guía de inicio rápido](https://docs.prontopaga.com/docs/first-steps), en donde encontrarás todo lo necesario para realizar tus primeras solicitudes de prueba. Es una excelente manera de familiarizarte con los conceptos básicos y ver nuestra API en acción.

## 📚 Nuestra Colección API

Cuando estés listo para profundizar, dirígete a la [referencia completa de nuestra API](https://docs.prontopaga.com/reference/create-payment). Aquí encontrarás toda la información técnica que necesitas para integrar y utilizar las funcionalidades que ofrecemos. Es el lugar perfecto para desarrolladores que buscan aprovechar al máximo nuestra API.

Sabemos que cada integración es única. Si tienes alguna duda o necesitas asistencia personalizada, no dudes en contactarnos por email. Estamos aquí para ayudarte en cada paso del camino.
