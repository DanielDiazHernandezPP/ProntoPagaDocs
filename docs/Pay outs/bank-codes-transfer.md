Para crear un nuevo retiro por transferencia bancaria en Chile, Ecuador o Perú, es necesario utilizar [este endpoint](https://docs.prontopaga.com/reference/bank-transfer-payout), en el cual se debe enviar el código bancario en el parámetro `bankCode`. En este artículo se muestran las listas de códigos bancarios por país.

## Brasil

```json
[
   {
      "code":633,
      "name":"Banco Rendimiento"
   }
]
```
