Esta guía recopila todas las instituciones financieras soportadas por ProntoPaga para pagos con Pix en Brasil.

Los valores son:

<br />

<HTMLBlock>{`
| Field        | Description                 |
| ------------ | --------------------------- |
| \`name\`       | Bank or institution name    |
| \`code\`       | Bank code (when applicable) |
| \`schema_skn\` | Internal identifier         |
| \`country\`    | Country code                |
| \`acronym\`    | Bank acronym                |
`}</HTMLBlock>

<br />

<br />
