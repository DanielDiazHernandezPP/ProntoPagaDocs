Crear un pago con esta modalidad consiste en hacer una solicitud a través de nuestra API. Esta solicitud podrá realizarse tanto para versión web como para versión mobile. Una vez realizada con éxito, el cliente podrá realizar sus pagos posteriores con un solo clic, a través de su cuenta de Yape, VíaBCP (banca por internet), Telecrédito (banca negocios) y Banca Móvil (_app_).
