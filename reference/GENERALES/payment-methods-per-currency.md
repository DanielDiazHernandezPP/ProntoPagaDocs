Muestra todos los métodos asignados al comercio según la moneda enviada. 

## Monedas

Se debe enviar en la URL el código ISO 4217 de la moneda.

| País    | Código    |
| :------ | :-------- |
| Brasil  | BRL / USD |
| Chile   | CLP / USD |
| Ecuador | USD       |
| Perú    | PEN / USD |
