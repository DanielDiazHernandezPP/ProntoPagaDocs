Para ver una lista de los bancos disponibles por país, haz una solicitud a este endpoint.

## Países

Se debe enviar en la URL el código de país en formato ISO 3166-1 alpha-2.

| País    | Código  |
| :------ | :------ |
| Brasil  | BR      |
| Chile   | CL      |
| Ecuador | EC      |
| Perú    | PE      |
